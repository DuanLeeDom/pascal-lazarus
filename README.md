## Configurando o Lazarus

1. Abra o Lazarus
2. Vá até **[Gerenciador de Pacotes Online]**
3. Baixe e instale os pacotes:
   - jvcllaz
   - Rx
   - zeosdbo
   - fpspreadsheet
